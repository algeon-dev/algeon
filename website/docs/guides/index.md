# Guides

The demos over four public datasets, and the workflow for discovering
installed GPU UDTFs, validating calls and checking whole-query GPU coverage.

## Available guides

- [Demo Datasets](./datasets/index.mdx) - the MerRec, Citation Network,
  Amazon Reviews and EMBER2024 demos, each with its SQL, captured results
  and provenance.
- [Discover & Validate GPU UDTFs](./gpu-udtf-discovery.mdx) - find
  installed cuGraph, cuVS and cuML UDTFs, inspect a contract, validate a call,
  and check whole-query GPU coverage, then see the sequence on a recorded
  session.
