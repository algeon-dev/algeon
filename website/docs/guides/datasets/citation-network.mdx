## Data scope

`papers` includes title, year, reported citation count, reference count, and
`primary_fos`, the source's primary field-of-study label.

| Table | Rows | Contents |
|---|---:|---|
| `citation_edges` | 45,564,149 | `src`, `dst`, `weight` = 1.0; sorted by `src` |
| `citation_edges_by_dst` | 45,564,149 | The same citations sorted by `dst` for reverse traversal |
| `papers` | 4,894,081 | `paper_id`, `title`, `year`, `venue`, `n_citation`, `n_references`, `primary_fos`, … |
| `paper_authors` | 14.9M | Paper-author links |
| `paper_fos` | 45.0M | Paper-field-of-study links |

`papers.n_citation` is AMiner's reported global count. In-graph degree counts
only edges present in this snapshot; the
[in-degree example](../../cugraph/udtfs/structure/cugraph_in_degrees_all.mdx#examples)
compares them.

The [Flight SQL guide](../../integration/flight-sql-server.mdx) covers client
connection. The [cuGraph function catalog](../../cugraph/udtfs/index.mdx)
contains more queries using these tables, including degree, centrality, and
layout examples.


**Seed paper records.** Queries use `paper_id` as the graph vertex. Titles can
repeat across records; the examples select title and year together when
identifying a seed.

| Paper | `paper_id` | Exact `title` in the corpus | `year` | Extra predicate |
|---|---|---|---|---|
| Transformer | `2963403868` | `Attention is all you need` | 2017 | |
| BERT | `2896457183` | `BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding` | 2018 | |
| AlexNet | `2163605009` | `ImageNet Classification with Deep Convolutional Neural Networks` | 2012 | |
| VGG | `1686810756` | `VERY DEEP CONVOLUTIONAL NETWORKS FOR LARGE-SCALE IMAGE RECOGNITION` | 2014 | |
| ResNet | `2194775991` | `Deep Residual Learning for Image Recognition` | 2016 | |
| LSTM | `2064675550` | `Long short-term memory` | 1997 | |
| PageRank | `2066636486` | `The anatomy of a large-scale hypertextual Web search engine` | 1998 | `venue = 'The Web Conference'` |

`Attention Is All You Need` with a capitalized `Is` matches a separate arXiv
record. Copy exact titles from this table or query `papers` for the intended
record.
