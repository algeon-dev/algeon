## Data scope

The deduplicated train, test and challenge splits contain **2,626,000**,
**605,929** and **6,315** files. Every challenge file is malicious, and 3,225
of them are Win32. Research preparation retains the first occurrence of each
SHA-256 within a split and assigns separate ID ranges to train, test and
challenge records.

The [historical reference search](../../cuvs/udtfs/cuvs_brute_force_knn.mdx?dataset=ember2024#examples)
