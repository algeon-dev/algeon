### Which mutually citing paper pairs have the largest publication-year gaps?

Before using citation direction as a timeline, inspect pairs whose references
run both ways despite a large gap in publication years. A strongly connected
component with two vertices contains such a pair. These are candidates for
checking editions and publication metadata, not proof of an incorrect citation.

Save one [SCC result](../graph-options.mdx#reuse-algorithm-results) so the pair
selection and both paper lookups use labels from the same execution. The query
excludes years outside 1900 through 2020 and returns one row per pair.

```sql
CREATE OR REPLACE TABLE scc_snapshot AS
SELECT vertex, label
FROM cugraph_strongly_connected_components(
  edges => (SELECT src, dst FROM citation_edges), directed => true);

WITH pairs AS (
  SELECT label FROM scc_snapshot GROUP BY label HAVING COUNT(*) = 2)
SELECT pa.year AS year_a, pa.title AS paper_a,
       pb.year AS year_b, pb.title AS paper_b,
       ABS(pa.year - pb.year) AS year_gap
FROM pairs x
JOIN scc_snapshot a ON a.label = x.label
JOIN scc_snapshot b ON b.label = x.label AND a.vertex < b.vertex
JOIN papers pa ON pa.paper_id = a.vertex
JOIN papers pb ON pb.paper_id = b.vertex
WHERE pa.year BETWEEN 1900 AND 2020 AND pb.year BETWEEN 1900 AND 2020
ORDER BY year_gap DESC, a.vertex, b.vertex
LIMIT 5;
```

| year_a | paper_a | year_b | paper_b | year_gap |
|---|---|---|---|---|
| 1965 | An analysis of floating-point addition | 2000 | Architecture of the IBM System/360 | 35 |
| 2013 | On Lipschitz Mappings Onto a Square | 2001 | A Multidimensional Generalization of the Erdös–Szekeres Lemma on Monotone Subsequences | 12 |
| 2001 | High-resolution passive polarimetric microwave mapping of ocean surface wind vector fields | 2013 | Digital Correlation Microwave Polarimetry: Analysis and Demonstration | 12 |
| 2013 | On parallel solution of linear elasticity problems. Part III: higher order finite elements | 2002 | On parallel solution of linear elasticity problems. Part II: Methods and some computer experiments. | 11 |
| 1991 | Large minimal realizers of a partial order II | 1980 | A generalization of Turán's theorem to directed graphs | 11 |

The largest gap among these isolated mutually citing pairs is 35 years,
between floating-point addition and IBM System/360 architecture papers.

The year gap prioritizes records for review. Larger strongly connected
components can also contain mutual citations; this query selects isolated
two-paper components to keep each case directly inspectable.
