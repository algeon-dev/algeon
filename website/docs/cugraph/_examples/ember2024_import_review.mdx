An analyst has an unlabeled Win32 file and wants candidates with related
imports, plus the symbols behind each match. Seed file `20005740` has 58
retained imports. It was selected by SHA-256 order among files with 10 to 100
retained imports and at least five neighbors in a separate histogram graph;
family labels were not used to select it.

Personalized PageRank creates a 25-file queue. Jaccard ranks import overlap
within that queue, and relational joins retrieve shared symbols and file
metadata. The sample-to-symbol edges were prepared before SQL, retaining
symbols occurring in 3 to 100 Win32 challenge files.
