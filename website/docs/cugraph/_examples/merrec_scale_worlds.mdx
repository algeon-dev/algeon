This example runs on the full [MerRec marketplace dataset](../../guides/datasets/merrec.mdx):
1,268,092,738 events from May through October 2023.

### Which shopping worlds do shared fans reveal across official categories?

Mercari files every listing under one of 17 top-level categories. Shoppers
do not browse that way. This statement chains two graph algorithms. First,
Jaccard scores the 12.5 million pairs among the 5,000 brands with the most
fans, using distinct user-brand likes as the graph. Pairs with a score of
at least 0.02 become a weighted brand graph, and Leiden partitions it at
resolution 3. SQL then counts each world's brands and returns the five
most-liked brands of every world with at least 15 brands.

```sql
WITH fans AS (
  SELECT -(e.user_id + 1) AS src, CAST(i.brand_id AS BIGINT) AS dst
  FROM merrec_events e JOIN merrec_items i ON i.item_id = e.item_id
  WHERE e.event_type = 'item_like' AND i.brand_id <> 0
  GROUP BY e.user_id, i.brand_id
), top_brands AS (
  SELECT dst AS brand_id, COUNT(*) AS fans FROM fans GROUP BY dst ORDER BY fans DESC, dst LIMIT 5000
), worlds AS (
  SELECT vertex AS brand_id, community AS world
  FROM cugraph_leiden(
    edges => (
      SELECT first AS src, second AS dst, CAST(similarity AS DOUBLE) AS weight
      FROM cugraph_jaccard(
        edges => (SELECT src, dst FROM fans),
        vertex_pairs => (SELECT a.brand_id AS first, b.brand_id AS second
                         FROM top_brands a JOIN top_brands b ON a.brand_id < b.brand_id),
        directed => false)
      WHERE similarity >= 0.02),
    directed => false, resolution => 3, seed => 42)
), members AS (
  SELECT w.world, n.brand_name, t.fans
  FROM worlds w
  JOIN top_brands t ON t.brand_id = w.brand_id
  JOIN (SELECT CAST(brand_id AS BIGINT) AS brand_id, MIN(brand_name) AS brand_name
        FROM merrec_items WHERE brand_id <> 0 GROUP BY brand_id) n ON n.brand_id = w.brand_id
), ranked AS (
  SELECT world, brand_name, fans,
         ROW_NUMBER() OVER (PARTITION BY world ORDER BY fans DESC, brand_name) AS rk
  FROM members
), sizes AS (
  SELECT world, COUNT(*) AS brands, SUM(fans) AS fan_links FROM members GROUP BY world
)
SELECT s.world, s.brands, s.fan_links, r.rk, r.brand_name, r.fans
FROM ranked r JOIN sizes s ON s.world = r.world
WHERE r.rk <= 5 AND s.brands >= 15
ORDER BY s.fan_links DESC, r.rk
;
```

Several worlds cut across the official taxonomy. The five most-liked brands
of the medical scrubs world are filed mostly under Men (Dickies), Kids
(Cherokee), Women (Sketchers, Koi) and Other (Grey's Anatomy).
Power tools sit with kitchen appliances (Milwaukee, DeWALT, Ninja,
KitchenAid). Golf, cameras, bridal wear and streetwear each form their own
world. A merchandising team could start navigation collections or campaign
audiences from these groups. The world numbers in the capture are labels
from this Leiden fit; three runs returned the same partition. The names in the table are editorial summaries
of each world's top brands.
