export const worldOf = brand => capture.records.find(row => row.brand_name === brand).world;

The query groups brands by overlapping audiences, including combinations
that cross catalog categories. It uses May to October 2023 likes: a fan is a
distinct shopper who liked a brand.

SQL reduces 182,889,825 like events to user-brand pairs and selects the
5,000 brands with the most fans. Jaccard measures shared audience divided
by combined audience for each brand pair. Similarities of at least 0.02
become edges for Leiden. The resulting groups join back to brand names.
Leiden uses the retained connections and currently ignores edge weights.

<CodeBlock language="sql" className="no-collapse">{capture.sql}</CodeBlock>

The query returns five leading brands for each of
{new Set(capture.records.map(row => row.world)).size} groups with at least
15 members. Three selected groups illustrate different audience relationships:
