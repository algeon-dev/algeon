This example runs on the full [MerRec marketplace dataset](../../guides/datasets/merrec.mdx):
1,268,092,738 events from May through October 2023.

### Which brand entries share almost the same fans?

The query builds the user-brand graph from every `item_like` event, takes
the 2,000 brands with the most fans, and scores all 1,999,000 brand pairs
with Jaccard in one call: shared fans divided by the union of both
audiences. SQL then joins brand names and fan counts and keeps the 30
highest scores.

```sql
WITH fans AS (
  SELECT -(e.user_id + 1) AS src, CAST(i.brand_id AS BIGINT) AS dst
  FROM merrec_events e JOIN merrec_items i ON i.item_id = e.item_id
  WHERE e.event_type = 'item_like' AND i.brand_id <> 0
  GROUP BY e.user_id, i.brand_id
), top_brands AS (
  SELECT dst AS brand_id, COUNT(*) AS fans FROM fans GROUP BY dst ORDER BY fans DESC, dst LIMIT 2000
), brands AS (
  SELECT CAST(brand_id AS BIGINT) AS brand_id, MIN(brand_name) AS brand_name
  FROM merrec_items WHERE brand_id <> 0 GROUP BY brand_id
)
SELECT ba.brand_name AS brand_a, bb.brand_name AS brand_b,
       a.fans AS fans_a, b.fans AS fans_b, r.similarity AS jaccard
FROM cugraph_jaccard(
  edges => (SELECT src, dst FROM fans),
  vertex_pairs => (SELECT a.brand_id AS first, b.brand_id AS second
                   FROM top_brands a JOIN top_brands b ON a.brand_id < b.brand_id),
  directed => false
) r
JOIN top_brands a ON a.brand_id = r.first
JOIN top_brands b ON b.brand_id = r.second
JOIN brands ba ON ba.brand_id = r.first
JOIN brands bb ON bb.brand_id = r.second
ORDER BY r.similarity DESC, brand_a
LIMIT 30;
```

Most of the highest-scoring pairs are one brand listed twice in the catalog:
TXT and Tomorrow X Together, Air Jordan and Jordan, Mugler and Thierry
Mugler, Yves Saint Laurent and YSL Yves Saint Laurent, Christian Dior and
Dior, A Bathing Ape and Bape, Hermès and HERMES, BabyBjorn and BABYBJÖRN.
The audiences give these entries away without any string matching. The
other pairs are distinct brands that one audience follows together, such
as Hello Kitty and Sanrio, Panini and Topps, or Carter's and Cat & Jack. A
catalog team can review the first group as merge candidates and use the
second group for cross-brand navigation. A high score alone does not prove
that two entries are the same brand; the names still need review.
