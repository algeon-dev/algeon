### How does the dense citation core divide into six research groups?

A six-group view of the dense citation core can show which catalog fields
dominate each group and where labels mix. The query first keeps papers with at
least 30 neighbors in the undirected citation graph, then partitions that core
and reports each group's two most common `primary_fos` labels. The call
passes the Int64 paper IDs directly; the
[vertex codebook](../graph-options.mdx#vertex-codebook) maps them to Int32
ids internally and decodes the result.

```sql
CREATE OR REPLACE TABLE kcore30_edges AS
SELECT src, dst
FROM cugraph_k_core(edges => (SELECT src, dst FROM citation_edges), k => 30);

WITH labeled AS (
  SELECT s.community AS cluster, p.primary_fos
  FROM cugraph_spectral_modularity_maximization(
    edges => (SELECT src, dst FROM kcore30_edges), n_clusters => 6,
    n_eigenvectors => 6, evs_tolerance => 0.00001) s
  JOIN papers p ON p.paper_id = s.vertex),
counts AS (
  SELECT cluster, primary_fos, COUNT(*) AS n FROM labeled GROUP BY 1, 2),
ranked AS (
  SELECT cluster, primary_fos, n,
         SUM(n) OVER (PARTITION BY cluster) AS members,
         ROW_NUMBER() OVER (PARTITION BY cluster ORDER BY n DESC, primary_fos) AS rn
  FROM counts)
SELECT cluster, members, primary_fos, n
FROM ranked WHERE rn <= 2
ORDER BY members DESC, rn;
```

The largest reported cluster has 28,994 papers, with convolutional neural
network and object detection as its two most common labels. Other rows include
probabilistic encryption, fuzzy logic, and rough set labels in smaller
clusters. The table shows only the top two labels per cluster, and cluster ids
are arbitrary. Labels with equal counts are ordered by name, so cluster 3
shows two of its three labels tied at 8 papers.
