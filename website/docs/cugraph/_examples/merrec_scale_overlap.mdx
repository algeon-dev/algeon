This example runs on the full [MerRec marketplace dataset](../../guides/datasets/merrec.mdx):
1,268,092,738 events from May through October 2023.

### Which athleisure brands draw most of their fans from lululemon's audience?

A brand's fans are the users who liked at least one of its listings. The
query turns all 182,889,825 `item_like` events into distinct user-brand
edges, then asks cuGraph for the overlap coefficient between lululemon and
every brand with at least 2,000 fans. Overlap divides the shared fans by
the smaller audience. lululemon has 201,207 fans, so for each smaller brand
the score is the share of that brand's own fans who also like lululemon.

```sql
WITH fans AS (
  SELECT -(e.user_id + 1) AS src, CAST(i.brand_id AS BIGINT) AS dst
  FROM merrec_events e JOIN merrec_items i ON i.item_id = e.item_id
  WHERE e.event_type = 'item_like' AND i.brand_id <> 0
  GROUP BY e.user_id, i.brand_id
), brand_fans AS (
  SELECT dst AS brand_id, COUNT(*) AS fans FROM fans GROUP BY dst
), brands AS (
  SELECT CAST(brand_id AS BIGINT) AS brand_id, MIN(brand_name) AS brand_name
  FROM merrec_items WHERE brand_id <> 0 GROUP BY brand_id
)
SELECT b.brand_name, f.fans, ROUND(r.similarity * f.fans) AS shared_fans, r.similarity AS overlap
FROM cugraph_overlap(
  edges => (SELECT src, dst FROM fans),
  vertex_pairs => (SELECT CAST(12630 AS BIGINT) AS first, brand_id AS second
                   FROM brand_fans WHERE fans >= 2000 AND brand_id <> 12630),
  directed => false
) r
JOIN brand_fans f ON f.brand_id = r.second
JOIN brands b ON b.brand_id = r.second
ORDER BY r.similarity DESC, b.brand_name
LIMIT 25;
```

User vertices are negated (`-(user_id + 1)`) so they never collide with
brand IDs in one undirected graph. Brand `12630` is lululemon athletica.

Ivivva, lululemon's former girls' line, leads: 73.8% of its fans also like
lululemon. The rest of the list reads like a competitor map for one
audience. It includes Alo, vuori, Beyond Yoga, Outdoor Voices, balance
athletica and CRZ YOGA, plus swim and loungewear labels such as Triangl and
Aviator Nation. A marketplace team could use the list to seed cross-brand
recommendations for lululemon shoppers, or to spot which smaller labels
depend on that audience. The scores measure shared likes, not purchases or
substitution.
