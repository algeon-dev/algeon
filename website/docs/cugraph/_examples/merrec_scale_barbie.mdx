### Which brands moved closer to Barbie fans after the July 2023 film release?

Barbie listings drew 732,440 views in June 2023 and 1,408,609 in July, the
month the film opened. This statement asks which other brands became more
connected to the Barbie audience at the same time. It builds two user-brand
like graphs, May-June and July-August, and makes four graph calls, two per
period:

- Personalized PageRank restarts every random walk at Barbie (brand `2595`),
  so its score measures closeness to the Barbie audience.
- Plain PageRank on the same graph measures overall popularity.
- `lift = personalized score / global score` removes the popularity
  baseline. Without it, Mattel, Disney and Nike lead every list.
- `lift_change` divides the July-August lift by the May-June lift.

```sql
WITH likes AS (
  SELECT DISTINCT -(e.user_id + 1) AS src, CAST(i.brand_id AS BIGINT) AS dst,
         e.event_time >= TIMESTAMP '2023-07-01 00:00:00' AS after_release
  FROM merrec_events e JOIN merrec_items i ON i.item_id = e.item_id
  WHERE e.event_type = 'item_like' AND i.brand_id <> 0
    AND e.event_time >= TIMESTAMP '2023-05-01 00:00:00'
    AND e.event_time < TIMESTAMP '2023-09-01 00:00:00'
), lift_before AS (
  SELECT p.vertex, p.value / r.value AS lift
  FROM cugraph_personalized_pagerank(
    edges => (SELECT src, dst FROM likes WHERE NOT after_release),
    personalization => (SELECT 2595 AS vertex, 1.0 AS value),
    directed => false) p
  JOIN cugraph_pagerank(
    edges => (SELECT src, dst FROM likes WHERE NOT after_release), directed => false) r
    ON r.vertex = p.vertex
), lift_after AS (
  SELECT p.vertex, p.value / r.value AS lift
  FROM cugraph_personalized_pagerank(
    edges => (SELECT src, dst FROM likes WHERE after_release),
    personalization => (SELECT 2595 AS vertex, 1.0 AS value),
    directed => false) p
  JOIN cugraph_pagerank(
    edges => (SELECT src, dst FROM likes WHERE after_release), directed => false) r
    ON r.vertex = p.vertex
), fans AS (
  SELECT dst AS brand_id,
         SUM(CASE WHEN after_release THEN 0 ELSE 1 END) AS fans_before,
         SUM(CASE WHEN after_release THEN 1 ELSE 0 END) AS fans_after
  FROM likes GROUP BY dst
), brands AS (
  SELECT CAST(brand_id AS BIGINT) AS brand_id, MIN(brand_name) AS brand_name
  FROM merrec_items WHERE brand_id <> 0 GROUP BY brand_id
)
SELECT b.brand_name, f.fans_before, f.fans_after,
       lb.lift AS lift_before, la.lift AS lift_after, la.lift / lb.lift AS lift_change
FROM lift_after la
JOIN lift_before lb ON lb.vertex = la.vertex
JOIN fans f ON f.brand_id = la.vertex
JOIN brands b ON b.brand_id = la.vertex
WHERE la.vertex > 0 AND la.vertex <> 2595
  AND f.fans_before >= 1000 AND f.fans_after >= 1000
ORDER BY lift_change DESC, b.brand_name
LIMIT 25;
```

The top four rows are known Barbie collaborations, and the listings confirm
them. In July and August, 30.6% of NYX likes were on listings whose name
contains "Barbie", up from 1.8% in May and June. The other rates are Primark
24.1% (from 1.6%), ALDO 19.0% (from 0.4%) and the AMC brand 9.2% (from 0%),
whose listings include cinema promo cups and popcorn tins. OPI and ZARA,
which also sold Barbie lines, show smaller shifts. Taylor Swift, Stanley and
the coffee chains rose through shared audience alone; their listings carry
almost no Barbie names. Nothing in the query names the film: the four graph
calls and two ratios find the tie-ins from likes. A partnerships or trend
team can use the same query for any seed brand and date split.
