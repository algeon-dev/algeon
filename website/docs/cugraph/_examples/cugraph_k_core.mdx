### Which papers stand out inside the densely connected citation core?

The k=30 core keeps papers with at least 30 neighbors inside the core when
citation links are treated as undirected. Its edge output is symmetrized, so a
retained neighbor pair appears in both directions. This threshold counts
undirected neighbors, not at least 30 citations received and 30 references made
by every paper. The nested call passes the core directly to PageRank and
returns its five highest-scoring papers:

```sql
SELECT p.year, p.title
FROM cugraph_pagerank(edges => (
  SELECT src, dst
  FROM cugraph_k_core(
    edges => (SELECT src, dst FROM citation_edges), k => 30)
)) r
JOIN papers p ON p.paper_id = r.vertex
ORDER BY r.value DESC
LIMIT 5;
```
