### Which widely cited papers also provide extensive bibliographies?

Papers with many incoming citations and many outgoing references can be useful
starting points for exploring a field's literature. This query selects papers
with more than 2,000 in-graph citations and more than 200 references in the
dataset.

```sql
SELECT d.in_degree, d.out_degree, p.year, p.title
FROM cugraph_degrees_all(edges => (SELECT src, dst FROM citation_edges)) d
JOIN papers p ON p.paper_id = d.vertex
WHERE d.out_degree > 200 AND d.in_degree > 2000
ORDER BY d.in_degree DESC
LIMIT 4;
```
