# Minimum Spanning Tree

SQL function: `cugraph_minimum_spanning_tree`

Official cuGraph reference: [Python API](https://docs.rapids.ai/api/cugraph/stable/api_docs/api/cugraph/cugraph.tree.minimum_spanning_tree.minimum_spanning_tree/)

Select a minimum-total-weight acyclic edge set, producing a spanning tree for a connected graph or a spanning forest otherwise.

## Signature

```sql
cugraph_minimum_spanning_tree(edges => (relation subquery), directed => value, renumber => value, construction_policy => value)
```
