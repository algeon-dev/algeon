# Edge Betweenness Centrality

SQL function: `cugraph_edge_betweenness_centrality`

Compute exact or explicitly seeded/k-sampled approximate edge betweenness centrality scores.

## Signature

```sql
cugraph_edge_betweenness_centrality(table_name [, src_col, dst_col [, weight_col [, options_json]]])
```

## Quickstart

```sql
SELECT * FROM cugraph_edge_betweenness_centrality('target_edges')
```

## JSON options

| Option | Type | Default | Constraints | Description |
| --- | --- | --- | --- | --- |
| `exact_vertex_threshold` | `UInt64` | `100000` |  | Maximum actual graph vertex count allowed for exact betweenness without explicit seeds or k. |
| `k` | `UInt64\|null` | `null` | min 1; mutually exclusive with `seeds` | Deterministic approximate seed count. Execution uses the first k distinct graph vertices in stable order and refuses k larger than the actual vertex count. |
| `normalized` | `Boolean` | `true` |  |  |
| `seeds` | `List<Int64>\|null` | `null` | mutually exclusive with `k` | Explicit seed vertices for approximate betweenness. Null requests exact all-vertex betweenness unless k is set. |
