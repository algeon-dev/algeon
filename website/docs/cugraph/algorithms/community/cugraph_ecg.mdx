# ECG

SQL function: `cugraph_ecg`

Detect communities with ensemble clustering for graphs.

## Use this when

Use this when a SQL statement needs ECG results over a registered edge relation.

## Signature

```sql
cugraph_ecg(table_name [, src_col, dst_col [, weight_col [, options_json]]])
```

## Quickstart

