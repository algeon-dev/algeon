# Spectral Modularity Maximization

UDTF: `cugraph_spectral_modularity_maximization`

Official cuGraph reference: [C API](https://docs.nvidia.com/cugraph/latest/api_docs/cugraph_c/community/#_CPPv440cugraph_spectral_modularity_maximizationPK25cugraph_resource_handle_tP19cugraph_rng_state_tP15cugraph_graph_t6size_t6size_tdidi6bool_tPP27cugraph_clustering_result_tPP15cugraph_error_t)

Partition vertices by running k-means on an embedding of the normalized graph Laplacian eigenvectors with the smallest eigenvalues. Modularity is not optimized directly.

## Quickstart

The call below supplies `edges` from registered relation `target_edges` with canonical `src` and `dst` columns and may include `weight`.

```sql
SELECT *
FROM cugraph_spectral_modularity_maximization(
  edges => (SELECT src, dst FROM target_edges)
);
```

## Limits

- seed sets the Lanczos start vector and the k-means initialization; the same seed can still yield a different partition because k-means centroid sums use floating-point atomics
- the native graph type indexes Int32 vertices only; Int64 and string vertex columns run through a per-call codebook that fails when the distinct vertex count exceeds Int32::MAX
- edge_id columns are rejected when Int64 vertices are mapped to Int32 ids
- cuGraph requires directed=false so the graph is constructed as an undirected/symmetric view
