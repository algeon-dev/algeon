# K-Core

UDTF: `cugraph_k_core`

Return the edges of the maximal subgraph whose vertices each have degree at least k within that subgraph.

## Quickstart

The call below supplies `edges` from registered relation `target_edges` with canonical `src` and `dst` columns and may include `weight`.

```sql
SELECT *
FROM cugraph_k_core(
  edges => (SELECT src, dst FROM target_edges)
);
```
