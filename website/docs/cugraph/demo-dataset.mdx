# Demo Dataset: Citation Network

Run PageRank over **4.9 million papers and 45.6 million citations**, then join
its scores to paper titles. The DBLP / AMiner V12 dataset is a fixed snapshot
from April 2020; an edge `src` → `dst` means “paper `src` cites paper `dst`.”

This walkthrough uses local Parquet files and the repository's SQL client.
After setup, the same tables work with the other cuGraph examples.

## Before you start

Use a Linux GPU host with the [native libraries built](../build/from-source.md#3-build-the-native-stack).
Run shell commands from the repository root. The full dataset requires a
12.5 GB source JSON and about 4.6 GB of generated Parquet, plus conversion
workspace. The recorded conversion took 17–19 minutes and 7.8 GB RAM on a
32-core host with local NVMe. GPU memory requirements depend on the query;
these preparation figures describe host resources.

## Prepare the data

Download and extract `dblp.v12.json` from the
[DBLP / AMiner V12 dataset](https://www.kaggle.com/datasets/mathurinache/citation-network-dataset).
Place it at `fixture/demo/citation_network/raw/dblp.v12.json`, then convert it:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pyarrow
fixture/fixture.sh graph dblp-ingest
```

The output is `fixture/demo/citation_network/v1/parquet/`. Skip this step
when those files already exist. The
[conversion reference](https://github.com/algeon-dev/algeon/blob/main/fixture/demo/citation_network/README.md)
includes the source checksum and layout details.

## Start the server

Build the server and SQL client:

```bash
cargo build --workspace --all-features --release --bin algeon_server --bin algeon_tools
```

Create a demo configuration for GPU 0 and start the server on localhost:

```bash
mkdir -p target
cat > target/citation-demo.toml <<'TOML'
[native]
execution_mode = "functions_only"

[[admission.device_profiles]]
device_ordinal = 0
TOML

ALGEON_SERVER_CONFIG_FILE="$PWD/target/citation-demo.toml" \
ALGEON_SERVER_GPU_DEVICES=0 \
ALGEON_SERVER_BIND=127.0.0.1:50051 \
ALGEON_SERVER_CUGRAPH_ENABLED=true \
flock /tmp/cudf-gpu.lock "${CARGO_TARGET_DIR:-target}/release/algeon_server"
```

Leave this terminal running. This configuration runs explicit cuGraph calls
on the GPU and ordinary SQL on the CPU.

## Register the tables

Open another terminal at the repository root. Define a shell helper for the
SQL client and check the connection:

```bash
sql() {
  "${CARGO_TARGET_DIR:-target}/release/algeon_tools" \
    flight-sql-query http://127.0.0.1:50051 "${1:-$(cat)}"
}
sql "SELECT 1 AS one"
```

The result should be a column named `one` containing `1`. Register the files:

```bash
citation_data="$PWD/fixture/demo/citation_network/v1/parquet"
sql "CREATE OR REPLACE EXTERNAL TABLE citation_edges STORED AS PARQUET LOCATION '$citation_data/edges_by_src.parquet'"
sql "CREATE OR REPLACE EXTERNAL TABLE citation_edges_by_dst STORED AS PARQUET LOCATION '$citation_data/edges_by_dst.parquet'"
sql "CREATE OR REPLACE EXTERNAL TABLE papers STORED AS PARQUET LOCATION '$citation_data/profiles_by_paper_id.parquet'"
sql "CREATE OR REPLACE EXTERNAL TABLE paper_authors STORED AS PARQUET LOCATION '$citation_data/paper_authors.parquet'"
sql "CREATE OR REPLACE EXTERNAL TABLE paper_fos STORED AS PARQUET LOCATION '$citation_data/paper_fos.parquet'"
```

Table registrations last until the server stops. After restarting, run this
registration block again; the Parquet files can be reused.

## Rank the papers

Run this in the client terminal:

```bash
sql <<'SQL'
SELECT p.title, p.year, r.value AS pagerank
FROM cugraph_pagerank(edges => (SELECT src, dst FROM citation_edges)) r
JOIN papers p ON p.paper_id = r.vertex
ORDER BY r.value DESC
LIMIT 5;
SQL
```

PageRank weights incoming citations by the scores of the citing papers.
A run recorded on 2026-09-26 returned these rows (scores rounded):

| title | year | pagerank |
|---|---|---|
| Finite automata and their decision problems | 1959 | 0.00139 |
| The Mathematical Theory of Communication | 1949 | 0.00134 |
| The reduction of two-way automata to one-way automata | 1959 | 0.00126 |
| The complexity of theorem-proving procedures | 1971 | 0.00073 |
| A mathematical theory of communication | 1948 | 0.00066 |

These scores describe the 2020 snapshot. They measure position in this
citation graph, and do not establish a paper's quality.

## Explore another question

Replace the query between `sql <<'SQL'` and `SQL` with another statement, or
connect an [interactive SQL client](../integration/flight-sql-server.mdx#use-an-interactive-client)
to the running server. Execute multi-statement examples one statement at a time.

- [Find a citation path from BERT to LSTM](./functions/traversal/cugraph_bfs.mdx#examples).
- [Compare citation communities with research fields](./functions/community/cugraph_louvain.mdx#examples).
- [Find papers with references similar to the Transformer](./functions/similarity/cugraph_jaccard.mdx#examples).

Examples use `CREATE OR REPLACE` for reusable views and result tables. Running
another example can replace shared names such as `ai_nodes` and `ai_edges`.

<details>
<summary>Table reference</summary>

| Table | Rows | Contents |
|---|---|---|
| `citation_edges` | 45.6M | `src`, `dst`, `weight` = 1.0; sorted by `src` |
| `citation_edges_by_dst` | 45.6M | The same citations sorted by `dst` for reverse traversal |
| `papers` | 4.9M | `paper_id`, `title`, `year`, `venue`, `n_citation`, `n_references`, `primary_fos`, … |
| `paper_authors` | 14.9M | Paper-author links |
| `paper_fos` | 45.0M | Paper-field-of-study links |

`papers.n_citation` is AMiner's reported global citation count. In-graph
degree counts only edges present here; the
[in-degree example](./functions/structure/cugraph_in_degrees_all.mdx#examples)
compares them.

</details>

<details id="seed-papers-used-in-the-examples">
<summary>Seed papers used in the examples</summary>

Use `paper_id` as the vertex ID. Titles can repeat across distinct records;
the examples resolve seeds by title and year, adding venue when needed.

| Paper | `paper_id` | Exact `title` in the corpus | `year` | Extra predicate |
|---|---|---|---|---|
| Transformer | `2963403868` | `Attention is all you need` | 2017 | |
| BERT | `2896457183` | `BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding` | 2018 | |
| AlexNet | `2163605009` | `ImageNet Classification with Deep Convolutional Neural Networks` | 2012 | |
| VGG | `1686810756` | `VERY DEEP CONVOLUTIONAL NETWORKS FOR LARGE-SCALE IMAGE RECOGNITION` | 2014 | |
| ResNet | `2194775991` | `Deep Residual Learning for Image Recognition` | 2016 | |
| LSTM | `2064675550` | `Long short-term memory` | 1997 | |
| PageRank | `2066636486` | `The anatomy of a large-scale hypertextual Web search engine` | 1998 | `venue = 'The Web Conference'` |

String equality is exact and case-sensitive: `Attention Is All You Need`
(capitalized) matches a separate arXiv record with a different id. Copy titles
from this table or from a query on `papers`, not from the published paper.
