# cuvs_pca

Principal-component analysis transform for dense vector rows.

Provider: `cuvs`. Domain: `vector`.

## Signature

```sql
cuvs_pca((input relation subquery), options_json)
```

## Execution call shape

Each relation argument is a parenthesized `SELECT` subquery. The execution function preserves those subqueries as real planner children; a bare table identifier or quoted table-name string is intentionally rejected.

```sql
SELECT * FROM cuvs_pca(
  (SELECT item_id, d0, d1 FROM input_vectors),
  '{"input":{"id":"item_id","vector":{"columns":["d0","d1"]}},"n_components":2}'
);
```
