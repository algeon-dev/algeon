# Vector Top-K

UDTF: `cuvs_top_k`

Official cuVS reference: [C++ API](https://docs.nvidia.com/cuvs/api-reference/cpp-api-selection-select-k)

Select the smallest or largest values in every dense vector row.

## Quickstart

The call below expects the registered relation `input_vectors` (the `input` role), passed as a parenthesized `SELECT` subquery.

```sql
SELECT *
FROM cuvs_top_k(
  input => (SELECT id, d0, d1 FROM input_vectors),
  k => 1,
  select => 'max'
)
ORDER BY row_ordinal, rank;
```

### Vector element types

Feature values must be `Float32`.

## Arguments and options

### Scalar SQL arguments

| Argument | Type | Required | Default | Constraints | Description |
| --- | --- | --- | --- | --- | --- |
| `k` | `integer` | yes | No default | minimum 1; maximum 4294967295 | Number of values selected from each row. |
| `select` | `string` | yes | No default | one of `"min"`, `"max"` | Select the minimum or maximum values. |

### Vector binding shapes

Each relation subquery must project an `id` field followed by either one or more feature fields of a supported element type (`Float32`) or exactly one list field of a supported element type, under any name.

For wide vectors, the projection order defines the feature dimensions. A list vector relation must contain no feature field beside `id` and its list field. Nullable field types are accepted. A null ID, feature value, list row, or list element fails the query.

## Output

| Column | Type | Nullable | Description |
| --- | --- | --- | --- |
| `row_ordinal` | `UInt64` | no | Zero-based physical ordinal of the evaluated input row; it disambiguates duplicate input IDs. Follows the input's top-level ORDER BY on output columns; unspecified without one. |
| `id` | `same_as_input.id` | no | Logical ID copied from the input relation. |

| `position` | `Int64` | no | Zero-based dimension index of the selected value within the input vector. |
| `value` | `Float32` | no | Selected Float32 input vector value; rank follows ascending values for min and descending values for max. |

## Limits

- k must not exceed the vector dimension. Empty input returns an empty result with the stable schema.
- Equal selected values are ordered by position; when ties straddle rank k, the selected positions among them are unspecified.
