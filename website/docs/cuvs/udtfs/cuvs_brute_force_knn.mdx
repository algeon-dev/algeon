# Brute-force kNN

UDTF: `cuvs_brute_force_knn`

Official cuVS reference: [C API](https://docs.nvidia.com/cuvs/api-reference/c-api-neighbors-brute-force)

Exact brute-force nearest-neighbor search over dense vectors.

## Quickstart

The call below expects the registered relations `dataset_vectors` (the `dataset` role) and `query_vectors` (the `queries` role), each passed as a parenthesized `SELECT` subquery.

```sql
SELECT *
FROM cuvs_brute_force_knn(
  dataset => (SELECT id, d0, d1 FROM dataset_vectors),
  queries => (SELECT id, d0, d1 FROM query_vectors),
  k => 8,
  metric => 'l2_expanded'
);
```

## Arguments and options

### Scalar SQL arguments

| Argument | Type | Required | Default | Constraints | Description |
| --- | --- | --- | --- | --- | --- |
| `k` | `integer` | yes | No default | minimum 1; maximum 4294967295 | Number of neighbors returned for each evaluated query row. |
| `metric` | `string` | yes | No default | one of `"l2_expanded"`, `"l2_sqrt_expanded"`, `"cosine"`, `"inner_product"` | Distance or score metric. Distance metrics rank lower values first; inner product ranks higher values first. |

### Vector binding shapes

Each relation subquery must project an `id` field followed by either one or more feature fields of a supported element type (`Float32`) or exactly one list field of a supported element type, under any name.

For wide vectors, the projection order defines the feature dimensions. A list vector relation must contain no feature field beside `id` and its list field. Nullable field types are accepted. A null ID, feature value, list row, or list element fails the query.

## Limits

- Builds an exact query-local index over the evaluated dataset relation; it does not persist an ANN index or replace a vector database.
- The evaluated dataset must be non-empty and k must not exceed its row count. An empty query relation may return an empty result with the stable schema.
- Dataset and query vector dimensions must match after both relation children are evaluated.
- Distances repeat between runs; neighbors that tie at the k-th distance can differ, because candidate merge order is not fixed.
