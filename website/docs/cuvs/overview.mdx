# cuVS SQL API

:::note[In progress]

The cuVS SQL surface is under active development. This page is a placeholder
that describes the intended shape; the `cuvs_*` table functions are not yet
available, and the details below may change before release.

:::

DataFusion Nexus will expose NVIDIA RAPIDS
[**cuVS**](https://github.com/NVIDIA/cuvs) as SQL table functions over
DataFusion SQL sessions — the same pattern already used by the
[cuGraph SQL API](../cugraph/overview.mdx). Each `cuvs_*` function will read a
relation of vectors, run a GPU vector operation, and return rows you can join
and filter alongside the rest of your query, over the data already in your
session — no separate vector store and no copy to keep in sync.
