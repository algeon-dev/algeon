The lookalike list contains shoppers whose taste vectors resemble earlier
Pokemon buyers. The query checks whether they later bought Pokemon and
whether they had already viewed it, against the simple rule of selecting
previous Pokemon viewers.

Earlier CTEs construct 64 category-preference features from views before
September 1, 2023. Each value is the square root of a shopper's share of views
in one of the 64 busiest categories. Eligibility requires 20 views. The seed
contains 1,302 eligible July to August Pokemon buyers; `candidates` excludes them.

The unfolded part of the SQL searches for 20 neighbors per seed buyer,
deduplicates the list, splits it by prior Pokemon views and joins September
to October purchases. The folded relations build the features in the same
query.

The two prior-view rows partition the lookalike audience. They are not
additional shoppers beyond the 19,124 in the first row.

Of the 132 later buyers in the lookalike list, 130 had already viewed Pokemon.
The never-viewed group's 0.034% purchase rate is close to the 0.033% eligible
baseline. This result supplies little evidence for finding a new audience.

The direct-viewer rule reaches 572 buyers from a much larger list. The
[campaign list](../../guides/datasets/merrec.mdx#audience-funnel) compares the
methods at equal list size. Features use the latest retained category attributes.
