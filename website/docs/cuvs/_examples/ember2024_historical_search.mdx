This [EMBER2024](../../guides/datasets/ember2024.mdx) example searches earlier
Win32 files for structural references to files in a later test period. The
current relations contain the full deduplicated splits. The corpus has
**1,560,000 Win32 training files** from weeks 0 to 51; the query selects the
first **10,000 Win32 test files** by ID from weeks 52 to 63. Each file is described
by a 512-element normalized byte and byte-entropy histogram.

The exact search returns ten historical references for each test query,
100,000 rows in all. It passes only IDs and vectors to `cuvs_brute_force_knn`.
Labels, family names, weeks and SHA-256 values join after the search. For test
file `10021000` from week 52, the first three references have the saved family
field `cosmu`:

| Rank | Historical file | Week | Squared-L2 distance |
| ---: | ---: | ---: | ---: |
| 1 | `2751446` | 27 | 0.00007534 |
| 2 | `3779432` | 37 | 0.00009656 |
| 3 | `4070733` | 40 | 0.00010586 |

The shared family field is a reason to inspect these references. It does not
make the nearest-neighbor distance a calibrated malware score or classify the
query file. The full-corpus capture has no independent CPU recall oracle, so
it supports retrieval and row counts without a full-scale quality claim.
