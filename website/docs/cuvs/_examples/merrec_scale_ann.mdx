The [MerRec dataset](../../guides/datasets/merrec.mdx) supplies `mr_taste64`, a prepared table of category-view-share vectors for 2,080,743 shoppers with at least 20 views before September 1. Each method searches the table against itself and returns ten neighbors per shopper.

Recall compares neighbor IDs with exact search. Some shoppers have identical vectors, so the last column also checks whether a returned distance is within `1e-5` of the exact tenth-neighbor distance.

| Method | Exact neighbor IDs kept | Within exact 10th distance |
|---|---:|---:|
| Exact brute force | 100% | 100% |
| CAGRA | 99.3% | 99.9% |
| IVF-Flat | 98.2% | 99.0% |
| IVF-PQ | 86.1% | 90.4% |

CAGRA and IVF-Flat retain more than 98% of exact neighbor IDs for this batch, while IVF-PQ retains 86.1%. These methods build a new index on every run, so a smaller query batch still pays that construction cost. Choosing a method depends on both recall and the expected batch size.

<summary>Executed SQL: CAGRA neighbors and recall</summary>

```sql
SELECT COUNT(*) AS neighbor_rows, COUNT(DISTINCT query_id) AS shoppers, AVG(distance) AS mean_distance
FROM cuvs_cagra(
  dataset => (SELECT * FROM mr_taste64 ORDER BY id),
  queries => (SELECT * FROM mr_taste64 ORDER BY id),
  k => 10, graph_degree => 32, intermediate_graph_degree => 64, build_algo => 'nn_descent'
);
```

```sql
WITH exact AS (
  SELECT query_id, neighbor_id, distance FROM cuvs_brute_force_knn(
    dataset => (SELECT * FROM mr_taste64 ORDER BY id),
    queries => (SELECT * FROM mr_taste64 ORDER BY id),
    k => 10, metric => 'l2_expanded')
), approx AS (
  SELECT query_id, neighbor_id, distance FROM cuvs_cagra(
    dataset => (SELECT * FROM mr_taste64 ORDER BY id),
    queries => (SELECT * FROM mr_taste64 ORDER BY id),
    k => 10, graph_degree => 32, intermediate_graph_degree => 64, build_algo => 'nn_descent')
), kth AS (
  SELECT query_id, MAX(distance) AS kth_distance FROM exact GROUP BY query_id
)
SELECT COUNT(*) AS approx_rows,
       CAST(COUNT(e.neighbor_id) AS DOUBLE) / COUNT(*) AS id_recall,
       AVG(CASE WHEN a.distance <= k.kth_distance + 1e-5 THEN 1.0 ELSE 0.0 END) AS within_exact_kth
FROM approx a
JOIN kth k ON k.query_id = a.query_id
LEFT JOIN exact e ON e.query_id = a.query_id AND e.neighbor_id = a.neighbor_id;
```
