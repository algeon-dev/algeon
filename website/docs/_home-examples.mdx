<p className={styles.exampleQuestion}>How far did AlexNet spread through three generations of citations?</p>
<p className={styles.exampleHow}>BFS follows citations backward from the 2012 paper; SQL counts the papers reached at each hop.</p>

```sql
SELECT b.distance, COUNT(*) AS papers, ROUND(AVG(p.year), 1) AS avg_year
FROM cugraph_bfs(
  edges => (SELECT dst AS src, src AS dst FROM citation_edges_by_dst),
  sources => (SELECT paper_id AS vertex FROM papers
              WHERE title = 'ImageNet Classification with Deep Convolutional Neural Networks'
                AND year = 2012),
  depth_limit => 3, output_mode => 'normalized') b
JOIN papers p ON p.paper_id = b.vertex
WHERE b.reachable
GROUP BY b.distance
ORDER BY b.distance;
```

<p className={styles.exampleQuestion}>Which of 1M catalog products are closest to each of 10,000 others?</p>
<p className={styles.exampleHow}>One call runs 10,000 exact nearest-neighbor searches over text embeddings computed before the query.</p>

```sql
SELECT n.query_id, q.title AS source_title, n.rank,
       n.neighbor_id, p.title AS candidate_title,
       1.0 - n.distance / 2.0 AS cosine_similarity
FROM cuvs_brute_force_knn(
  dataset => (SELECT * FROM product_corpus_1000000),
  queries => (SELECT * FROM product_queries_10000),
  k => 10, metric => 'l2_expanded') n
JOIN semantic_products_text q ON q.id = n.query_id
JOIN semantic_products_text p ON p.id = n.neighbor_id
ORDER BY n.query_id, n.rank;
```

<TabItem value="malware" label="Malware files">

<p className={styles.exampleEyebrow}><span>cuML</span>EMBER2024 challenge split · 6,315 malicious files</p>
<p className={styles.exampleQuestion}>Which files does a pretrained malware model score highest, and why?</p>
<p className={styles.exampleHow}>LightGBM scores every file on the GPU; Top-K ranks SHAP attributions computed on the CPU beforehand.</p>

```sql
SELECT p.id, m.sha256, m.file_type, m.week_id, p.prediction,
       t.rank, g.group_name, t.value AS positive_log_odds_contribution
FROM cuml_forest_predict(
  input => (SELECT id, vector FROM ember_research_vectors_challenge ORDER BY id),
  model => 'EMBER2024_all.model', model_format => 'lightgbm') p
JOIN cuvs_top_k(
  input => (SELECT id, vector FROM ember_attributions ORDER BY id),
  k => 3, select => 'max') t ON t.id = p.id
JOIN ember_feature_groups g ON g.group_index = t.position
JOIN ember_metadata_challenge m ON m.id = p.id
WHERE p.prediction >= 0.99 AND t.value > 0
ORDER BY p.prediction DESC, p.id, t.rank
LIMIT 30;
```

<TabItem value="marketplace" label="Shopper browsing">

<p className={styles.exampleEyebrow}><span>cuGraph</span>MerRec · Mercari US browsing graph, October 2023</p>
<p className={styles.exampleQuestion}>Which collectibles share an audience with Nintendo games?</p>
<p className={styles.exampleHow}>Personalized PageRank picks 100 groups near the Nintendo seed; Jaccard scores their shared viewers.</p>

```sql
SELECT m.product_id, m.brand_name, m.category, m.leaf_category,
       m.viewers, r.similarity AS audience_jaccard
FROM cugraph_jaccard(
  edges => (SELECT src, dst FROM mr_audience),
  vertex_pairs => (
    SELECT CAST(672 AS INT) AS first, candidates.vertex AS second
    FROM (
      SELECT vertex, value
      FROM cugraph_personalized_pagerank(
        edges => (SELECT src, dst, weight FROM mr_edges),
        personalization => (SELECT id AS vertex, CAST(1.0 AS DOUBLE) AS value
                            FROM mr_nodes WHERE product_id = '15928_1315'))
      WHERE vertex <> 672
      ORDER BY value DESC, vertex LIMIT 100) candidates),
  directed => false) r
JOIN mr_nodes m ON m.id = r.second
WHERE m.category = 'Toys & Collectibles' AND m.viewers >= 30
ORDER BY r.similarity DESC, m.product_id
LIMIT 10;
```
