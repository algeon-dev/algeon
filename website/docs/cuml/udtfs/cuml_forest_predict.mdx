# Forest Predict

UDTF: `cuml_forest_predict`

Official cuML reference: [nvForest](https://docs.nvidia.com/nvforest/latest/)

Score Float32 rows with a pretrained XGBoost, LightGBM, or Treelite forest through nvForest.

## Quickstart

Register the relations referenced by the parenthesized `SELECT` clauses below. For metadata validation, the descriptor names `input_vectors`.

```sql
SELECT id, prediction
FROM cuml_forest_predict(
  input => (SELECT id, d0, d1, d2, d3 FROM t),
  model => 'scorer.json',
  model_format => 'xgboost_json'
)
ORDER BY row_ordinal;
```

## Limits

- Scores pretrained XGBoost (JSON, UBJSON, legacy binary), LightGBM text, and Treelite checkpoint forests with nvForest. Multi-target models are rejected at planning.
- Features must be Float32 without null values and match the model feature count. Forests with double-precision thresholds widen the features to Float64 on the device.
- output =&gt; 'class_index' requires a model with at least two outputs and resolves ties to the lowest class index.
- model resolves under the server-configured models root, and files above max_model_bytes are rejected. The model is read and imported each time a query is planned; there is no model cache.
