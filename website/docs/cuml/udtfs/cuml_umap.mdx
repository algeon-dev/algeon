# UMAP

UDTF: `cuml_umap`

Official cuML reference: [Python API](https://docs.nvidia.com/cuml/latest/api/generated/cuml.manifold.UMAP/)

cuML UMAP fits a deterministic, query-local manifold embedding for dense feature rows.

## Quickstart

Register the relations referenced by the parenthesized `SELECT` clauses below. For metadata validation, the descriptor names `input_vectors`.

```sql
SELECT id, dim_0, dim_1
FROM cuml_umap(
  input => (SELECT id, d0, d1 FROM t),
  n_neighbors => 5
)
ORDER BY row_ordinal;
```

## Limits

- L2SqrtExpanded distance, brute-force kNN, and deterministic mode are fixed.
- Float64 features, as wide columns or list elements, are narrowed to Float32 on the device before training or inference. Each value rounds to the nearest Float32, which keeps about seven significant digits; a value beyond the Float32 range becomes infinite and fails the query.
- Empty input returns an empty result. Other inputs require n_neighbors &lt; rows, checked at execution.
- min_dist must not exceed spread. The fit and embedding are query-local.
- random_state seeds the spectral initialization, the edge shuffle, and negative sampling.
