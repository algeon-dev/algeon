# HDBSCAN

UDTF: `cuml_hdbscan`

Official cuML reference: [Python API](https://docs.nvidia.com/cuml/latest/api/generated/cuml.cluster.hdbscan.HDBSCAN/)

cuML HDBSCAN fits density-based clusters and returns query-local labels and membership probabilities.

## Quickstart

Register the relations referenced by the parenthesized `SELECT` clauses below. For metadata validation, the descriptor names `input_vectors`.

```sql
SELECT id, cluster_id, probability
FROM cuml_hdbscan(
  input => (SELECT id, d0, d1 FROM t),
  min_cluster_size => 5
)
ORDER BY row_ordinal;
```

## Limits

- L2SqrtExpanded distance and brute-force kNN are fixed.
- Float64 features, as wide columns or list elements, are narrowed to Float32 on the device before training or inference. Each value rounds to the nearest Float32, which keeps about seven significant digits; a value beyond the Float32 range becomes infinite and fails the query.
- Empty input returns an empty result. Other inputs require min_samples &lt; rows, min_cluster_size &lt;= rows, and max_cluster_size &lt;= rows; row-dependent conditions are checked at execution.
- Cluster ID -1 denotes noise. The fit and output are query-local.
