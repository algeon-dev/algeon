A security analyst needs to compare both benign files flagged and malicious
files missed. Both models train on 1,560,000 Win32 files from weeks 0 to 51,
using the same 512 normalized byte and byte-entropy histogram features.
Evaluation uses 359,994 later Win32 files from weeks 52 to 63.

The statement fits logistic regression and random forest, predicts labels for
the later files, then joins the known labels and aggregates the errors.
Predictions are class IDs `0` and `1`. Test labels are joined after prediction.

The later test set contains 179,994 benign and 180,000 malicious files.
