A two-dimensional projection can help choose reviews to read together, but
coordinates alone do not explain a complaint. This query projects 9,967
sampled low-rating headphone reviews from 1,024 dimensions and joins the
output IDs to product names and review text.

UMAP's output is a relation that can be joined to the review records in the
same statement. The text remains available to check any explanation proposed
from a projection. Two-dimensional distance is not a defect score or proof
that reviews describe the same issue; the projection does not label topics.
