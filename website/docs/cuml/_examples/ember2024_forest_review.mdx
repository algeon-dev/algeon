The query scores all 6,315 challenge files with a pretrained LightGBM model
using 2,568 features, then joins the three largest positive feature-block
contributions for each file. A review queue built from this result carries
both the score and the inputs behind it.

The model is loaded by `cuml_forest_predict`. CPU LightGBM `pred_contrib` was
run before SQL, with its 2,568 contributions summed into 12 named blocks.
`cuvs_top_k` ranks those prepared values; the query does not compute SHAP.
