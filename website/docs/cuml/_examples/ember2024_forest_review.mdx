A review queue should retain both the model score and the feature contributions
available for inspection. This query scores all 6,315 challenge files with a
pretrained LightGBM model using 2,568 features, then joins the three largest
positive feature-block contributions for each file.

The model is loaded by `cuml_forest_predict`. CPU LightGBM `pred_contrib` was
run before SQL, with its 2,568 contributions summed into 12 named blocks.
`cuvs_top_k` ranks those prepared values; the query does not compute SHAP.

The histogram and strings blocks contribute most among this file's returned
positive blocks. They identify model inputs for further inspection. Negative
contributions and model bias are absent from the table, and these values do

The query combines model inference, ranking of prepared attributions and
metadata joins. It produces a review queue linked to source file records.
GPU predictions matched CPU LightGBM within `3.0e-8` maximum absolute error
across all 6,315 files. Every challenge label is malicious, so this cohort
cannot measure false-positive rate or establish score calibration.
