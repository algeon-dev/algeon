An audience planner has capacity to review 55,404 shoppers. The comparison
uses either the highest XGBoost scores or everyone who bought in the previous
30 days, then counts September buyers in each list.

The model was trained before the query on features preceding August 1, 2023,
with purchases in the next 30 days as labels. Training and model review are
separate preparation steps; SQL loads `propensity_xgb.json` for inference.

The earlier `test` CTE computes ten activity and price features from June to August,
retains shoppers with at least 20 views, and attaches the September outcome.
The open part scores those features, ranks shoppers and evaluates both budgets.

At equal list size, the model includes 1,980 more observed buyers than the
recent-purchase rule. The smaller model list has higher precision but reaches
fewer buyers. These counts give a planner a budget comparison without treating
model score alone as evidence of value.

Algeon combines SQL feature construction, an externally trained model and
outcome aggregation in one statement. Filters and list size remain query
choices. Prices use the latest retained item attributes; that limitation
also applies to training. Performance at another monthly cutoff and
incremental campaign impact have not been measured.
