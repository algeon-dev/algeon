The recent-purchase rule selects the 55,404 shoppers who bought in the
previous 30 days. The model list keeps the same number of highest-scoring
shoppers, and the query counts September buyers in each list.

The model was trained before the query on features preceding August 1, 2023,
with purchases in the next 30 days as labels. Training and model review are
separate preparation steps; SQL loads `propensity_xgb.json` for inference.

The earlier `test` CTE computes ten activity and price features from June to August,
retains shoppers with at least 20 views, and attaches the September outcome.
The visible query segment below scores those features, ranks shoppers, and evaluates both budget allocations.
