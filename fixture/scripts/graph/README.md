# SNAP Graph Fixtures

`snap_ingest.py` downloads SNAP graph edge lists and writes Parquet layouts under
`./fixture/data/snap` by default (a gitignored, per-host symlink to fast local
storage). Generated bytes stay out of git.

Tier generation:

```bash
.venv/bin/python fixture/scripts/graph/snap_ingest.py --tier 1
.venv/bin/python fixture/scripts/graph/snap_ingest.py --tier 2
.venv/bin/python fixture/scripts/graph/snap_ingest.py --tier 3
```

Smoke generation without the full SNAP download/convert cost:

```bash
.venv/bin/python fixture/scripts/graph/snap_ingest.py --dataset soc-pokec --max-edges 100000 --skip-communities --skip-profiles --overwrite
```

Each dataset root contains:

- `source.json` with SNAP URL, compressed-byte SHA-256, and dataset metadata.
- `parquet/edges_by_src.parquet` globally clustered by `(src, dst, edge_id)`.
- `parquet/edges_by_dst.parquet` globally clustered by `(dst, src, edge_id)`.
- `parquet/communities_*.parquet` for datasets with SNAP ground-truth communities.
- `parquet/profiles_by_user_id.parquet` for datasets with SNAP node/user profiles, currently `soc-pokec`.
- `manifest.json` with row counts, row-group samples, and registration SQL.
